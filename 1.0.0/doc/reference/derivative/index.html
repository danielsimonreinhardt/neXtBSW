    Derivative description¶

    Manufacturer facts of one MCU derivative, read-only for boards and projects: memory regions, peripheral instances and their clocks, pin multiplexing per package, clock limits, core, MPU and interrupt controller. One file per derivative under mcudb/<family>/, plus one generated pin multiplexing table per package.

    Configuration level: Derivative. File: mcudb/<family>/<derivative>.yaml, mcudb/<family>/<part>.pinmux.yaml. Schema: Derivative, PinmuxTable in tools/nxconfig/model.py.

    254 fields in 44 objects. 0 fields have no description in the schema and 0 numeric fields have no unit; they are marked missing in schema and missing. How to read the tables: reference overview.

    Derivative file mcudb/<family>/<derivative>.yaml¶

    (top level)¶

    Derivative file mcudb/<family>/<derivative>.yaml: manufacturer facts of one MCU derivative.

    Field Type Unit Required Default Allowed values Description
    schema_version integer yes 1 Version of the file format; currently 1.
    derivative object yes Identification, core and packages of the derivative.
    memory list of object no [] Memory regions (flash, RAM, EEPROM window).
    instances map of string to object yes Peripheral instances; key: instance name as in the reference manual (e.g. FlexCAN0, LPSPI1), which boards use in instance.
    pinmux map of string to object no {} Pin multiplexing per package; key: package name from derivative.packages.
    device_header object no null Vendor device header of the derivative.
    clock object no null Clock facts: oscillators, PLL and frequency limits.
    mpu object no null Memory protection unit. Left out: no MPU described; code that needs it stops with an error.
    uid object no null Unique chip identification. Left out: unknown; a project with a bootloader needs it.
    vim object no null Vectored interrupt manager, VIM cores only. Left out: not described, no interrupt ranks possible.
    eeprom_emulation object no null Codes of the one-time partition of the emulated EEPROM (s32k1xx FlexNVM). Left out: the derivative has no partitionable emulated EEPROM; a project with nvm.partition is rejected.
    pin_interrupts object no null Pins that can raise an interrupt on an edge, their lines and vectors. Left out: not described; a project with pin_events is rejected.
    comparators list of object no [] After R1. Analogue comparators with reference DAC whose output reaches a fault input of a PWM timer (hardware threshold). Empty: not described; a project with hw_thresholds is rejected.
    trigger_router object no null After R1. Trigger router between peripherals (PWM timer triggers to sample sequencers and fault inputs). Left out: not described; a project with sample_groups is rejected.
    sample_sequencers list of object no [] Sample sequencers that convert a list of channels on one ADC after one hardware trigger. Empty: not described; a project with sample_groups is rejected.

    derivative¶

    Identification and core of the derivative, packages and where its facts come from.

    Field Type Unit Required Default Allowed values Description
    derivative.name string yes at least 1 character, pattern ^[A-Za-z0-9_]+$ Derivative name as the manufacturer writes it (e.g. S32K144); boards refer to it in board.mcu.
    derivative.family string yes at least 1 character, pattern ^[A-Za-z0-9_]+$ Family of the derivative (e.g. s32k1xx, stm32): selects the family clock model, the generators and the platform code.
    derivative.core string yes Processor core, a key of the core table of tools/nxconfig (e.g. cortex-m4f).
    derivative.fpu string no null none, sp, dp FPU variant: none, single precision (sp) or double precision (dp). Left out: the only variant the core has.
    derivative.nvic_priority_bits integer bit no null 2 to 8 NVIC cores: number of implemented interrupt priority bits.
    derivative.features list of string no [] item: lmem_cache Optional core features: lmem_cache is the LMEM processor code cache (S32K14x), switched on at start-up.
    derivative.packages list of string yes at least 1 item Package names of the derivative (e.g. LQFP100); board.package is one of them.
    derivative.pin_pattern string yes Regular expression of the pin names; every pin a board names must match it.
    derivative.sources list of string no [] Documents and repository files the facts of this file come from.
    derivative.verify boolean no false true: the entry as a whole is not confirmed by a source in the repository.
    derivative.example boolean no false true: format example only, not for real projects; using it gives a warning.
    derivative.jlink_device string no null J-Link device name, if it differs from the derivative name.
    derivative.pyocd_target string no null pyOCD target type, if it differs from the derivative name in lower case.
    derivative.openocd_target string no null OpenOCD target script, e.g. target/stm32f4x.cfg.

    memory[]¶

    Memory of the derivative. Partitioning (bootloader, application, NvM) is decided by the project.

    Field Type Unit Required Default Allowed values Description
    memory[].name string yes at least 1 character, pattern ^[A-Za-z0-9_]+$ Region name (e.g. PFLASH, SRAM_L); the project refers to it in memory.
    memory[].kind string yes code_flash, data_flash, ram, eeprom_ram Kind of memory: program flash, data flash, RAM or the RAM window of an emulated EEPROM.
    memory[].start integer none yes ≥ 0 Start address of the region.
    memory[].size integer byte yes > 0 Size of the region.
    memory[].sector_size integer byte no null > 0 Flash: smallest erasable unit. A flash region needs it or sectors.
    memory[].sectors list of object no null Flash with unequal sectors (e.g. STM32F4): sector table from the start of the region.
    memory[].program_size integer byte no null > 0 Flash: smallest programmable unit (S32K1 phrase: 8 bytes).
    memory[].source string no null Document the values of this entry come from (data sheet, reference manual, schematic), with section or page.
    memory[].verify boolean no false true: the entry is not confirmed by its source; checks that depend on it warn instead of trusting it.

    memory[].sectors[]¶

    count consecutive flash sectors of size bytes (sector table of a flash with unequal sectors).

    Field Type Unit Required Default Allowed values Description
    memory[].sectors[].size integer byte yes > 0 Size of each sector of the group.
    memory[].sectors[].count integer none yes > 0 Number of consecutive sectors of this size.

    instances.<key>¶

    One peripheral instance of the derivative. class_ is family neutral (timer, not FTM or TIM).

    Field Type Unit Required Default Allowed values Description
    instances.<key>.class string yes adc, timer, spi, can, uart, i2c, flexio, ethernet, qspi, i2s, gpio Family-neutral kind of the peripheral (timer, not FTM or TIM; gpio for a GPIO port that is an instance of its own, rm4x GIOA). Decides which board and project entries may use the instance.
    instances.<key>.channels integer none no null > 0 Timer: number of channels of the instance. GPIO port: number of pins of the port (their pin function is GPIO in the pin multiplexing table).
    instances.<key>.first_channel integer none no 0 ≥ 0 Timer only: number of the first channel, 1 where the manufacturer counts from 1 (TIM1_CH1).
    instances.<key>.resolution_bits integer bit no null > 0 ADC only: resolution of the converter.
    instances.<key>.channel_pattern string no null ADC only: regular expression of the external channel names (e.g. SE([0-9]\|1[0-5])), checked against adc[].channel of the board.
    instances.<key>.internal_channels list of string no [] ADC only: names of the inputs without pin (bandgap, reference, supply monitor) a project may use in adc_internal.
    instances.<key>.message_buffers integer none no null > 0 CAN only: number of message buffers (mailboxes) of the instance. Left out: unknown.
    instances.<key>.clock object no null Functional clock of the instance. Left out: unknown; a project that uses the instance gets an error.
    instances.<key>.verify boolean no false Same as memory[].verify.

    instances.<key>.clock¶

    Functional clock of one peripheral instance (s32k1xx: clock gate of the PCC, fields PCCn.PCS/CGC).

    Fact and decision are split (doc/architecture/README.md, section 4):

    • the derivative names what the hardware allows - the selectable sources (sources), the asynchronous outputs the instance is wired to (divider) and the limit of the functional clock (max_hz), each with its source like every mcudb value,
    • the project decides which of them is used (project.yaml peripheral_clocks.<instance>),
    • default is the choice that applies to a project which decides nothing. Without it an instance the project uses and does not choose a clock for is an error, so no value has to be invented for a derivative whose data sheet values are missing.

    An instance without a clock select (select bus, core or none) has no sources: there is nothing to decide. Neither has an instance that runs on a named clock domain of the global clock module (domain, rm4x: VCLK, VCLK2, VCLKA1): its frequency follows from the domain the family clock model sets up.

    Field Type Unit Required Default Allowed values Description
    instances.<key>.clock.sources list of string no [] item: SOSC, SIRC, FIRC, SPLL Clock sources the clock select of the instance offers. Empty for an instance without clock select (then select is set).
    instances.<key>.clock.divider list of integer no [] item: 1, 2 Asynchronous outputs DIVx of the sources the instance is wired to (1: DIV1, 2: DIV2).
    instances.<key>.clock.default object no null Clock choice that applies when the project names none. Left out: a project that uses the instance must choose its clock in peripheral_clocks.
    instances.<key>.clock.max_hz integer Hz no null > 0 Maximum functional clock of the instance (limit of the DIVx output) as the reference manual states it. Left out: no limit stated.
    instances.<key>.clock.select string no null bus, core, none For an instance without clock select: bus or core (runs on that clock), none (the clock is chosen inside the peripheral, e.g. s32k1xx FlexCAN CTRL1.CLKSRC).
    instances.<key>.clock.domain string no null at least 1 character, pattern ^[A-Za-z0-9_]+$ For an instance without clock select of its own that runs on a named clock domain of the global clock module (rm4x: VCLK, VCLK2, VCLKA1): the name of that domain, a key of clock.max_hz. Given alone, without sources, select, divider, default and max_hz.
    instances.<key>.clock.source string no null Same as memory[].source.
    instances.<key>.clock.verify boolean no false Same as memory[].verify.
    instances.<key>.clock.note string no null Free text for the reader; no tool evaluates it.

    instances.<key>.clock.default¶

    One clock of a peripheral: source and the asynchronous output of that source it is wired to.

    Field Type Unit Required Default Allowed values Description
    instances.<key>.clock.default.select string yes SOSC, SIRC, FIRC, SPLL Clock source that feeds the instance (s32k1xx: SOSC, SIRC, FIRC or SPLL, the value of PCCn.PCS).
    instances.<key>.clock.default.divider integer no null 1, 2 Asynchronous output of the source the clock is taken from: 1 for DIV1, 2 for DIV2. In a project entry it may be left out when the derivative allows only one output.

    device_header¶

    Vendor device header the family code includes for this derivative (mcu.h).

    Field Type Unit Required Default Allowed values Description
    device_header.file string yes Include path of the header, e.g. 3rdparty/nxp/S32K148.h.
    device_header.describes string yes at least 1 character, pattern ^[A-Za-z0-9_]+$ Derivative the header was written for; may be a superset of this one.
    device_header.source string no null Where the header comes from or which file adapts it.
    device_header.generated_by string no null regdesc2header The header is not in the repository but generated at configure time. regdesc2header: from the register description mcudb/<family>/registers/*.yaml, written from the reference manual for a family without SVD, with mcudb/<family>/tools/regdesc2header.py. Left out: the header must be in the include path.

    clock¶

    Clock facts of the derivative. Which source feeds what is the family clock model (tools/nxconfig/clock.py).

    Field Type Unit Required Default Allowed values Description
    clock.internal map of string to integer Hz no {} key: at least 1 character, pattern ^[A-Za-z0-9_]+$; value: > 0 Frequency of each internal oscillator; key: its name (e.g. FIRC: 48000000).
    clock.oscillator object no null External oscillator input. Left out: the derivative has none.
    clock.pll object no null PLL limits. Left out: the derivative has no PLL.
    clock.lpo object no null Frequency range of the low power oscillator that clocks the MCU watchdog. Left out: not described; a family whose watchdog runs on it (s32k1xx) cannot derive its safety timing then (error at clock.lpo).
    clock.max_hz map of string to integer Hz no {} key: at least 1 character, pattern ^[A-Za-z0-9_]+$; value: > 0 Maximum frequency per clock domain (core, bus, ...) in the run mode the drivers use.
    clock.system_source_max_hz map of string to object no {} key: at least 1 character, pattern ^[A-Za-z0-9_]+$ Stricter domain maxima that apply only while a given source feeds the system clock (s32k14x: BUS_CLK 40 MHz with the SPLL as system clock). Key: system clock source of the family clock model.
    clock.output_max_hz object no null Maximum of every asynchronous clock output in the run mode the drivers use (s32k1xx: SPLLDIV1, FIRCDIV2, ...). The family clock model chooses the output dividers from it (the smallest divider within the limit). Left out: the outputs stay undivided.
    clock.pcc map of string to object no {} key: at least 1 character, pattern ^[A-Za-z0-9_]+$ Clock gates of peripherals that are not listed in instances because no generator configures them yet, but whose clock the clock driver switches on (s32k1xx: LPIT, LPTMR0). Key: name of the gate.
    clock.flash_wait_states object no null Flash read wait states per band of the flash clock. Left out: not described (the flash needs none, or the family code does not configure them).
    clock.source_numbers object no null Number of every clock source in the source select fields (rm4x GHVSRC). Needed by a family clock model with numbered sources (rm4x). Left out: the family has none.
    clock.external_max_hz object no null Maximum of every external clock input (rm4x EXTCLKIN1, EXTCLKIN2); keys are names of source_numbers. Left out: no external clock input described.
    clock.oscillator_monitor object no null Window of the oscillator clock monitor. Left out: no monitor described; the board's oscillator is only checked against oscillator.
    clock.domain_dividers map of string to object no {} key: at least 1 character, pattern ^[A-Za-z0-9_]+$ How each named clock domain is derived (rm4x: VCLK, VCLK2, VCLKA1, RTICLK); key: domain name, which is also its key in max_hz. Peripheral instances name their domain in instances.<x>.clock.domain.
    clock.source string no null Same as memory[].source.
    clock.verify boolean no false Same as memory[].verify.

    clock.oscillator.max_hz integer Hz yes > 0 Highest crystal or clock frequency the oscillator input accepts.
    clock.oscillator.source string no null Same as memory[].source.
    clock.oscillator.verify boolean no false Same as memory[].verify.

    clock.pll¶

    PLL fed by the oscillator: output = oscillator / input_divider * multiplier / output_divider.

    Field Type Unit Required Default Allowed values Description
    clock.pll.input_hz list of integer Hz yes exactly 2 items; item: > 0 [min, max] of the PLL reference after the input divider.
    clock.pll.vco_hz list of integer Hz yes exactly 2 items; item: > 0 [min, max] of the VCO frequency (reference * multiplier).
    clock.pll.input_divider list of integer none yes exactly 2 items; item: > 0 [min, max] of the input divider between oscillator and PLL reference.

    vim¶

    Vectored interrupt manager of the derivative (core with interrupt controller vim).

    The priority of a request is its channel number (0 highest). The project gives ranks as with an NVIC; checks.py turns them into a channel order over the channels that are not fixed.     Field Type Unit Required Default Allowed values Description

    Partition of the emulated EEPROM (NVM-07): the codes of the one-time partition command of the derivative.

    Field Type Unit Required Default Allowed values Description
