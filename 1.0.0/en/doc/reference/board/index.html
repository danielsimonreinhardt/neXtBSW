    Board description¶

    What is fitted and wired on one printed circuit board: derivative and package, crystal, debug interface, fitted parts and how they are connected, buses, ADC channels with the circuit in front of the pin, PWM groups with their power stage, digital inputs and outputs. Hardware only - what the software uses of it is decided by the project.

    Configuration level: Board. File: boards/<board>/board.yaml. Schema: Board in tools/nxconfig/model.py.

    230 fields in 47 objects. 0 fields have no description in the schema and 0 numeric fields have no unit; they are marked missing in schema and missing. How to read the tables: reference overview.

    Board file boards/<board>/board.yaml¶

    (top level)¶

    Board file boards/<board>/board.yaml: what is fitted and wired on one printed circuit board.

    Field Type Unit Required Default Allowed values Description
    schema_version integer yes 1 Version of the file format; currently 1.
    board object yes Identification of the board: derivative, package, clock, debug.
    devices list of object no [] Fitted components the software talks to.
    spi list of object no [] SPI buses.
    can list of object no [] CAN connections.
    uart list of object no [] UARTs.
    i2c list of object no [] I2C buses.
    rails list of object no [] Supply rails that sensor circuits refer to.
    adc list of object no [] Analog inputs with the circuit in front of the pin.
    pwm list of object no [] After R1. PWM groups with their power stage.
    input_capture list of object no [] Input capture channels.
    dio object no {} Digital inputs and outputs.
    comparators object no null After R1. Signals at inputs of an analogue comparator of the MCU (hardware threshold). Left out: none.

    board¶

    Identification of the board: derivative, package, supply, clock and debug connection.

    Field Type Unit Required Default Allowed values Description
    board.name string yes at least 1 character, pattern ^[A-Za-z0-9_]+$ Board name; by convention the same as the folder boards/<board>.
    board.mcu string yes at least 1 character, pattern ^[A-Za-z0-9_]+$ Derivative fitted on the board (derivative.name of a file in mcudb/).
    board.package string yes Package of the fitted derivative, one of its derivative.packages; selects the pin multiplexing table.
    board.supply_v number V no null Supply voltage of the MCU. The STM32 generator chooses the flash wait states for it. Left out: not stated.
    board.clock object no {} Fitted crystal or oscillator.
    board.debug object no null Debug connection. Left out: the build has no flash targets.
    board.adc_reference_mv integer mV no null > 0 Voltage at the ADC reference input (VREFH): scaling base of all ADC channels.
    board.description string no null Short description of the board for the reader.

    board.clock¶

    Clock sources fitted on the board.

    Field Type Unit Required Default Allowed values Description
    board.clock.sosc_hz integer Hz no null > 0 Frequency of the fitted crystal or external oscillator; the clock model derives PLL and dividers from it. Left out: none fitted.

    board.debug¶

    Debug connection of the board: interface, probe and clock of the flash targets.

    Field Type Unit Required Default Allowed values Description
    board.debug.interface string yes Debug interface of the connector: JTAG, SWD or cJTAG.
    board.debug.probe string no null Debug probe (e.g. J-Link EDU Mini, ST-LINK/V2-1, CMSIS-DAP, XDS110); selects the flash tools. Left out: J-Link.
    board.debug.speed_khz integer kHz no null > 0 Clock of the debug interface. Left out: the safe default of the flash targets (1000 kHz).

    devices[]¶

    Fitted component and, if a module drives it, its wiring to the module's connections (module.yaml connect).

    Field Type Unit Required Default Allowed values Description
    devices[].name string yes at least 1 character, pattern ^[A-Za-z0-9_]+$ Device name, unique on the board; buses (spi[].device, can[].phy) and the project (modules.<device>) refer to it.
    devices[].part string yes Part number of the fitted component (e.g. TMC6200-TA); matched against the parts patterns of the module manifests.
    devices[].module string no null at least 1 character, pattern ^[A-Za-z0-9_]+$ Module (driver) that drives the device. Left out: the module whose manifest lists the part.
    devices[].connect map of string to string no {} key: at least 1 character, pattern ^[A-Za-z0-9_]+$; value: at least 1 character, pattern ^[A-Za-z0-9_]+$ Wiring of the module's connections: module connection -> board entry (digital output or input, ADC channel).
    devices[].note string no null Free text for the reader; no tool evaluates it.
    devices[].source string no null Document the part facts come from (data sheet).
    devices[].verify boolean no false true: fitting or wiring is not confirmed by the source.
    devices[].pins map of string to object no {} key: at least 1 character, pattern ^[A-Za-z0-9_]+$ IO-33: wiring of pins of the part itself that are no MCU connection (e.g. the HVIO and EN pins of a system basis chip): pin -> use. The module manifest lists the pins and the uses it serves (module.yaml pins). Left out: not described, the module leaves such pins as it found them.

    devices[].pins.<key>¶

    IO-33: how the board wires one pin of a device (board.yaml devices[].pins.<pin>).

    Field Type Unit Required Default Allowed values Description
    devices[].pins.<key>.use string yes at least 1 character, pattern ^[a-z][a-z0-9_]*$ What the pin does on this board, one of the uses the module lists for it (module.yaml pins.<pin>.uses, e.g. none for a pin that is not wired, wake_input for a wake-up input).
    devices[].pins.<key>.note string no null Free text for the reader; no tool evaluates it.
    devices[].pins.<key>.verify boolean no false true: the wiring is not confirmed by the source.

    adc[].scale¶

    Value in mV = pin voltage * factor + offset_mv; divider: factor = (r_top + r_bottom) / r_bottom.

    Field Type Unit Required Default Allowed values Description
    adc[].scale.factor number V/V no null > 0, finite Ratio of the measured voltage to the pin voltage. Give either factor or divider; neither: 1.
    adc[].scale.divider object no null Resistor divider the factor is calculated from.
    adc[].scale.offset_mv integer mV no 0 -2^31 to 2^31-1 Offset added after the factor.
    adc[].scale.verify boolean no false Same as rails[].verify.

    adc[].scale.divider¶

    Resistor divider in front of an ADC pin; only the ratio of the two resistors counts.

    Field Type Unit Required Default Allowed values Description
    adc[].scale.divider.r_top number Ω yes ≥ 0 Resistor between the measured voltage and the pin.
    adc[].scale.divider.r_bottom number Ω yes > 0 Resistor between the pin and ground.

    adc[].sensor (kind: linear)¶

    value = pin_mV * gain_num / gain_den + offset (unit).

    Field Type Unit Required Default Allowed values Description
    adc[].sensor.source string no null Data sheet or schematic the values come from.
    adc[].sensor.verify boolean no false true: a value is not confirmed by the source.
    adc[].sensor.note string no null Free text for the reader; no tool evaluates it.
    adc[].sensor.kind string yes linear Circuit type: linear characteristic of the pin voltage.
    adc[].sensor.unit string yes mV, mA, ohm, ddegC, permille Unit of the value the circuit delivers (adc.phys of the channel).
    adc[].sensor.gain_num integer unit of unit per mV yes -2^31 to 2^31-1 Numerator of the gain; not 0.
    adc[].sensor.gain_den integer none no 1 > 0, ≤ 2^31-1 Denominator of the gain, for gains that are no integer.
    adc[].sensor.offset integer unit of unit no 0 -2^31 to 2^31-1 Offset added after the gain.

    adc[].sensor (kind: shunt_amplifier)¶

    Current in mA = (pin_mV - reference_mV) * gain_den / gain / shunt (shunt amplifier with output offset).

    Field Type Unit Required Default Allowed values Description
    adc[].sensor.source string no null Data sheet or schematic the values come from.
    adc[].sensor.verify boolean no false true: a value is not confirmed by the source.
    adc[].sensor.note string no null Free text for the reader; no tool evaluates it.
    adc[].sensor.kind string yes shunt_amplifier Circuit type: shunt resistor with current sense amplifier; delivers the current in mA.
    adc[].sensor.shunt_uohm integer µΩ yes > 0, ≤ 2^31-1 Resistance of the shunt.
    adc[].sensor.gain integer V/V yes > 0, ≤ 2^31-1 Voltage gain of the amplifier; for a gain that is no integer, gain / gain_den.
    adc[].sensor.gain_den integer none no 1 > 0, ≤ 2^31-1 Denominator of the gain, for gains that are no integer.
    adc[].sensor.reference object yes Output voltage of the amplifier at 0 A (its REF pins).
    adc[].sensor.output_min_mv integer mV no null 0 to 2^31-1 Lower end of the linear output range (swing to GND); below it the channel reports a range error. Left out: no limit.
    adc[].sensor.output_max_mv integer mV no null 0 to 2^31-1 Upper end of the linear output range (swing to the supply); above it the channel reports a range error. Left out: no limit.

    A voltage of the board a sensor circuit refers to: a named rail (board.rails) or a fixed value.

    adc[].sensor (kind: divider)¶

    Voltage in mV at the connector = pin_mV * (r_top + r_bottom) / r_bottom.

    Field Type Unit Required Default Allowed values Description
    adc[].sensor.source string no null Data sheet or schematic the values come from.
    adc[].sensor.verify boolean no false true: a value is not confirmed by the source.
    adc[].sensor.note string no null Free text for the reader; no tool evaluates it.
    adc[].sensor.kind string yes divider Circuit type: resistor divider; delivers the voltage at the connector in mV.
    adc[].sensor.r_top_ohm integer Ω yes 0 to 2^31-1 Resistor between the connector and the pin.
    adc[].sensor.r_bottom_ohm integer Ω yes > 0, ≤ 2^31-1 Resistor between the pin and ground.

    adc[].sensor.kind string yes pullup Circuit type: pull-up resistor to a supply; delivers the resistance to GND at the connector in ohm.

    adc[].sensor.supply object yes Voltage the pull-up is connected to.
    adc[].sensor.diode_mv integer mV no 0 0 to 2^31-1 Forward voltage of a diode in series to the pull-up; 0: none.
