# Startup templates per core architecture (PLAT-10)

| Architecture | File | Cores | State |
|---|---|---|---|
| ARMv6-M | `armv6m/startUp.S` | Cortex-M0+ (S32K116/S32K118) | template, compiled and linked in the M0+ build test |
| ARMv7-M | `../port/main/src/bsp/startUp.S` (family port template) | Cortex-M4F | in the family port since PLAT-23, not yet merged with the template here; since SYS-170 its external vectors come from the same generated `startup/nxIrqVectors.inc` |

## Contract

- **Linker symbols** (same as the ARMv7-M startup and the S32K1 application linker script): `__StackTop`,
  `__isr_vector` (section `.isr_vector`), `__DATA_RAM`/`__DATA_RAM_END` (RAM cleared before the copy, ECC),
  `__etext` + `__data_start__`/`__data_end__`, `__DATA_ROM_GENERAL` + `__data_general_start__`/`__data_general_end__`,
  `__DATA_ROM_RX` + `__LAUNCH_FROM_RAM_START`/`__LAUNCH_FROM_RAM_END`, `__bss_start__`/`__bss_end__`,
  `__MPU_BSS_START`/`__MPU_BSS_END`, section `.__startUpSection` (`__start`, boot header of the bootloader).
- **Integration functions:** `boardInit()` (before the RAM initialization, no global data), `main()`.
- **Interrupt list** `startup/nxIrqVectors.inc` in the include path: one line per external interrupt number, from 0,
  `NX_IRQ_VECTOR(<handler>)` or `NX_IRQ_RESERVED()`. Handler names unique. The list belongs to the derivative (IRQ
  names of the device header) and should be generated from mcudb (ARCH-05/08); ARMv6-M allows at most 32 entries
  (assembler error otherwise). Without `NX_STARTUP_SAFE_ISR` every handler is weak and defaults to `DefaultISR`; `NMI_Handler`, `HardFault_Handler`,
  `SVC_Handler`, `PendSV_Handler`, `SysTick_Handler` as well (FreeRTOS maps its handlers to these names in
  `FreeRTOSConfig.h`).
- **Interrupt frame of the safety shell (SYS-170, SYS69-S1):** the application assembles the startup with
  `NX_STARTUP_SAFE_ISR` (`port/main/CMakeLists.txt`). Then every external vector points at `Safe_<handler>` and SysTick at
  `Safe_SysTick_Handler` - the `SAFE_ISR` wrappers of `port/safety/safeLifecycle/src/safeLifecycle/IsrWrapper.cpp`,
  which close the MPU gate of the protected RAM around the handler (list `interrupts/nxSafeIsrVectors.h`, tools/bswgen),
  and the weak `DefaultISR` defaults of the handlers live there, not in the startup. The safety handlers keep their
  own `Safe_<handler>` (FTFC fault, ERM double fault, naked watchdog path, halt deadman on LPIT0 channel 1 as an
  alias of its handler). The ARMv7-M startup of the family port
  does the same unconditionally and fills the numbers behind the derivative's last vector with `DefaultISR` up to
  its 255 entries and the TRIM word. `tools/elfcheck` checks the linked application (`isr-unwrapped`).
- **VTOR** is written with `__isr_vector` (application behind the bootloader). S32K116/S32K118 have VTOR
  (`__VTOR_PRESENT 1` in the S32DS headers); a Cortex-M0 without VTOR would need the table at address 0.
- No FPU, no MemManage/BusFault/UsageFault/DebugMon vectors (reserved on ARMv6-M), one NVIC ICER/ICPR register.
- Not included: the S32K14x "user TRIM" word at the end of the ARMv7-M table, the boot header (`bootHeader.S` of the
  family port, data only; since PLAT-12 without an `.arch` directive, so it assembles for both architectures).
- **In the application since PLAT-12:** `platforms/s32k1xx/port/main/CMakeLists.txt` selects this template for ARMv6-M;
  `startup/nxIrqVectors.inc` is generated by `tools/bswgen` from the IRQ list of the derivative's device header
  (`mcudb/tools/svd2header.py irqvectors` is the same function as a command). The list names the handlers; the
  names a derivative spells differently are unified by `FAMILY_IRQ_HANDLERS` in bswgen (SYS-170: without the
  `Safe_` prefix, which the startup adds to every vector).
- `DefaultISR` loops on a local label: `b DefaultISR` bound to the strong `DefaultISR` of OpenBSW's interrupt manager,
  which a Thumb-1 branch cannot reach in a full application (`R_ARM_THM_JUMP11`, PLAT-12).

## Verification

`platforms/common/test/test_cortex_m0plus.py`: object `v6S-M` without FP attributes, only Thumb-1 instructions,
vector table of the linked test ELF (length 48 words, reserved entries 0, port handlers under the vector names, weak
IRQ handlers = `DefaultISR`), 33 interrupts rejected. Not run on hardware.
